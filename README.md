# Schedules Lesson
Telegram bot for daily class schedules and lesson reminders.

> [!NOTE]
> This is the first bot I’ve created. There might be bugs or incorrect code.

## Project information
1. The project is written for the **Telegram** app.
2. The project is written in `JavaScript` and runs on `Node.js`.
3. The bot is built with the [`telegraf`](https://www.npmjs.com/package/telegraf) package.

## What the bot does
1. At **08:00**, the bot sends the full schedule for the day.
2. When a lesson starts, the bot sends a notification so you don't miss it.
